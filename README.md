# Dear Data 100 --> My cats

## About
Tracking how many times a day my cats interact with me every weekday, across different 
days, to see when and how often it actually happens.

## Data
Each row in data represents one observation: a day, a time-of-day window, 
and how many interactions happened in that window. Logged consistently across 
the week to build toward 100+ observations.

## Sketch
Sketch contains the Processing sketch that visualises the data.
- For creativity, i plan to use paws for the foundation of my data, having each claw differ in size depending on the number of interactions on the weekday
